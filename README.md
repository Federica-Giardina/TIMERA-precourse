# TIMERA — Preliminary learning

Self-study material for participants of **TIMERA** (Training Initiative for Modelling Epidemic Response in Africa), to be completed before the first face-to-face module:

- **P1** Introduction to R
- **P2** Statistical and epidemiological concepts
- **P3** Mathematical background

The rendered book is in `_book/` after rendering (open `_book/index.html`); a Word version is produced alongside it.

## Rendering

Requires R (≥ 4.4) with `tidyverse`, `readxl`, `knitr` and `rmarkdown`, and Quarto (bundled with RStudio). In RStudio: *Build → Render Book*, or in a terminal:

```
quarto render
```

## Source

This repository is **generated** from the main course repository, <https://github.com/Federica-Giardina/TIMERA>, where the same chapters form the *Preliminary learning* part of the course book. Changes should be made there and exported with `py preparatory/export.py` (see `preparatory/README.md` in the main repository); edits made directly in this repository will be overwritten.
