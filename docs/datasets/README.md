# TIMERA — Datasets used in Module 1

This folder contains all datasets used in the chapters and practical sessions of Module 1, as CSV files (comma-separated, UTF-8, dates in the format `YYYY-MM-DD`, missing values as empty cells). They can be read in R with `readr::read_csv()`, or opened in Excel or any statistical software. All files are also available in a single archive, `TIMERA-datasets.zip`.

In the course book, the datasets of the R package `outbreaks` are loaded directly from the package (e.g. `outbreaks::ebola_sim_clean`); the CSV versions here contain the same data. The other files are read from the `data/` folder of the course project.

The folder is generated by `datasets/make_datasets.R` (run from the root of the project); it should not be edited by hand.

## Historical and simulated outbreaks (R package `outbreaks`)

| File | Content | Rows | Used on |
|---|---|---|---|
| `influenza_england_1978_school.csv` | Influenza in a boarding school, England, 1978 (763 boys): daily number of boys confined to bed (`in_bed`) and convalescent | 14 | Days 1, 4, 6 |
| `measles_hagelloch_1861.csv` | Measles in Hagelloch, Germany, 1861: one row per child, with the probable infector, dates of prodrome, rash and death, age, gender, family, school class and location | 188 | Days 1, 2 |
| `ebola_sierraleone_2014.csv` | Ebola virus disease in Sierra Leone, 2014: confirmed cases with age, sex, status, dates of onset and sampling, district and chiefdom | 11,903 | Days 1, 6 |
| `ebola_sim_linelist.csv` | Simulated Ebola outbreak, line list **with data-entry errors** (spelling variants of hospitals, inconsistent dates, missing values), for the cleaning practical | 5,888 | Day 2 |
| `ebola_sim_contacts.csv` | Simulated Ebola outbreak: infector–infectee pairs and setting of transmission | 3,800 | Day 2 |
| `ebola_sim_clean_linelist.csv` | Simulated Ebola outbreak, cleaned line list: generation, dates of infection, onset, hospitalisation and outcome, outcome, gender, hospital and coordinates | 5,829 | Day 2 |
| `ebola_sim_clean_contacts.csv` | Infector–infectee pairs of the cleaned simulated outbreak | 3,800 | Day 2 |
| `mers_korea_2015_linelist.csv` | MERS in the Republic of Korea, 2015: line list with age, sex, place of infection, hospital, and dates of exposure, onset, report, diagnosis and death | 162 | Day 3 (alternative to own data) |
| `mers_korea_2015_contacts.csv` | MERS, Republic of Korea, 2015: transmission pairs and type of exposure | 98 | Day 3 (alternative to own data) |
| `ebola_kikwit_1995.csv` | Ebola virus disease in Kikwit, Democratic Republic of the Congo, 1995: daily numbers of cases by date of onset and of deaths | 192 | Day 3 (alternative to own data) |

Source: R package `outbreaks` (Jombart T. et al., <https://www.repidemicsconsortium.org/outbreaks/>, licence GPL ≥ 2), which documents the original source of each dataset (`?outbreaks::ebola_sierraleone_2014`, etc.). The `ebola_sim` datasets are simulated and do not describe a real outbreak.

## Conditions of use

The datasets are provided for teaching. Users should cite the original sources listed above. Real line lists contain no personal identifiers; the participants' own data used during the course must be anonymised before use and must not be added to this folder.
