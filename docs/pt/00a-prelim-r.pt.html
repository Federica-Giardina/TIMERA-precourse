P1 Introdução ao R

Aprendizagem preliminar — noções básicas de R e RStudio

NotaTradução provisória

Este capítulo foi traduzido do inglês e está em revisão. As observações são bem-vindas.

DicaObjetivos de aprendizagem

No final deste capítulo, os participantes deverão ser capazes de:

  1. Utilizar a interface do RStudio, criar e guardar scripts e trabalhar num projeto RStudio.
  2. Criar objetos dos principais tipos de dados e selecionar elementos de vetores e de data frames.
  3. Utilizar funções incorporadas e pacotes, consultar as páginas de ajuda e escrever funções simples.
  4. Importar um conjunto de dados e manipulá-lo com as principais funções do tidyverse.
  5. Produzir gráficos simples com o ggplot2.
  6. Utilizar instruções condicionais e ciclos for.

Este capítulo apresenta os elementos básicos da linguagem R. Não pressupõe experiência prévia de programação. A aplicação do R à análise de dados de surtos e à modelação é o tema de livro do curso: Own data and programming models in R no Módulo 1, e o R é utilizado nas sessões práticas de todos os capítulos do livro. As instruções de instalação encontram-se em Apêndice A — Instalação do R e do RStudio.

Os participantes sem experiência prévia em R devem completar os tutoriais interativos de R da Applied Epi (sessões 1 a 6), disponíveis gratuitamente em inglês, francês, português e espanhol em https://www.appliedepi.org/resources/tutorials.html. Cada sessão requer cerca de 2 a 4 horas:

P1.2 O RStudio e os projetos

O RStudio tem quatro painéis: o editor de scripts (em cima, à esquerda), onde o código é escrito e guardado; a consola (em baixo, à esquerda), onde o código é executado; o ambiente (em cima, à direita), que lista os objetos em memória; e o painel de ficheiros, gráficos e ajuda (em baixo, à direita). Uma linha de código de um script é executada com Ctrl + Enter (Cmd + Enter no macOS); o texto a seguir a # é um comentário e não é executado.

O trabalho deve ser organizado num projeto RStudio (File → New Project). Todos os caminhos dos ficheiros são então relativos à pasta do projeto, de modo que a análise pode ser transferida para outro computador sem alterações.

P1.4 Objetos e atribuição

Os valores são guardados em objetos com o operador de atribuição <-. Os nomes dos objetos distinguem maiúsculas de minúsculas, não podem começar por um algarismo e devem ser informativos.

population <- 250000
cases <- 375
incidence <- cases / population * 100000
incidence
## [1] 150

P1.5 Tipos de dados e vetores

Um vetor é uma sequência ordenada de valores do mesmo tipo, criada com c(). Os principais tipos são numérico, carácter (texto), lógico (TRUE/FALSE), fator (variável categórica com níveis definidos) e data.

age <- c(4, 12, 35, 67, 23)                              # numérico
sex <- c("female", "male", "male", "female", "female")   # carácter
vaccinated <- c(TRUE, FALSE, TRUE, TRUE, FALSE)          # lógico
age_group <- factor(c("0-14", "0-14", "15-64", "65+", "15-64"),
                    levels = c("0-14", "15-64", "65+"))  # fator
visit <- as.Date(c("2026-03-01", "2026-03-04", "2026-03-04", "2026-03-09", "2026-03-12"))

class(age); class(sex); class(vaccinated); class(age_group); class(visit)
## [1] "numeric"
## [1] "character"
## [1] "logical"
## [1] "factor"
## [1] "Date"
length(age)
## [1] 5

As operações aritméticas e as comparações são vetorizadas: aplicam-se a cada elemento.

age * 12                   # idade em meses
## [1]  48 144 420 804 276
age >= 15                  # vetor lógico
## [1] FALSE FALSE  TRUE  TRUE  TRUE
sum(vaccinated)            # TRUE conta como 1
## [1] 3
mean(vaccinated)           # proporção de vacinados
## [1] 0.6
table(age_group)
## age_group
##  0-14 15-64   65+ 
##     2     2     1

## [1]  4 35

P1.5.2 Valores em falta

Os valores em falta são representados por NA. A maioria das funções de resumo devolve NA se algum valor estiver em falta, a menos que se especifique na.rm = TRUE.

weight <- c(12.5, NA, 70.2, 64.0, 58.3)
mean(weight)
## [1] NA
mean(weight, na.rm = TRUE)
## [1] 51.25
is.na(weight)
## [1] FALSE  TRUE FALSE FALSE FALSE
sum(is.na(weight))
## [1] 1

P1.6 Funções e pacotes

Uma função recebe entradas (argumentos) e devolve um resultado. Os argumentos podem ser indicados pela posição ou pelo nome; os argumentos com valores predefinidos podem ser omitidos.

round(123.456, digits = 1)
## [1] 123.5
seq(from = 0, to = 20, by = 5)
## [1]  0  5 10 15 20
rep("A", times = 3)
## [1] "A" "A" "A"
paste("District", 1:3)
## [1] "District 1" "District 2" "District 3"

Os pacotes fornecem funções adicionais. Um pacote é instalado uma única vez com install.packages("nome") e carregado em cada sessão com library(nome). A página de ajuda de uma função é apresentada com ?nome_da_funcao, p. ex. ?seq.

P1.6.1 Escrever funções

As funções definidas pelo utilizador evitam a repetição de código:

incidence_per_100k <- function(cases, population) {
  cases / population * 100000
}
incidence_per_100k(cases = 375, population = 250000)
## [1] 150
incidence_per_100k(cases = c(10, 50, 120), population = c(20000, 80000, 150000))
## [1] 50.0 62.5 80.0

P1.7 Instruções condicionais e ciclos

if executa código apenas quando uma condição é verdadeira; ifelse() aplica uma condição a cada elemento de um vetor.

coverage <- 0.82
if (coverage >= 0.95) {
  message("Meta de cobertura atingida")
} else {
  message("Cobertura abaixo da meta")
}

ifelse(age >= 15, "adulto", "criança")
## [1] "criança" "criança" "adulto"  "adulto"  "adulto"

Um ciclo for repete um bloco de código para cada valor de uma sequência:

savings <- numeric(5)        # vetor vazio de comprimento 5
savings[1] <- 100
for (year in 2:5) {
  savings[year] <- savings[year - 1] * 1.10   # juro de 10% ao ano
}
savings
## [1] 100.00 110.00 121.00 133.10 146.41

P1.8 Listas

Uma lista pode conter objetos de tipos e comprimentos diferentes e é frequentemente utilizada para guardar parâmetros ou os resultados de uma análise.

parameters <- list(country = "Mozambique", year = 2026, rates = c(0.1, 0.25))
parameters$country
## [1] "Mozambique"
parameters[["rates"]]
## [1] 0.10 0.25

P1.9 Data frames

Um data frame é uma tabela em que cada coluna é um vetor e cada linha uma observação. Um tibble é a versão tidyverse de um data frame.

library(tidyverse)

patients <- tibble(
  id = 1:5,
  age = age,
  sex = sex,
  vaccinated = vaccinated,
  visit = visit
)
patients
## # A tibble: 5 × 5

##   <int> <dbl> <chr>  <lgl>      <date>

## 4     4    67 female TRUE       2026-03-09
## 5     5    23 female FALSE      2026-03-12
patients$age            # uma coluna

P1.9.1 Manipulação de dados com o dplyr

As principais funções do pacote dplyr realizam, cada uma, uma única operação e são combinadas com o pipe |>:

Função Operação
filter() selecionar linhas
select() selecionar colunas
mutate() criar ou modificar colunas
arrange() ordenar linhas
group_by() e summarise() resumir por grupo
count() contar linhas por grupo
left_join() combinar duas tabelas através de uma coluna comum 
patients |>
  filter(age >= 15) |>
  mutate(age_months = age * 12) |>
  select(id, sex, age, age_months) |>
  arrange(desc(age))
## # A tibble: 3 × 4
##      id sex      age age_months
##   <int> <chr>  <dbl>      <dbl>
## 1     4 female    67        804
## 2     3 male      35        420
## 3     5 female    23        276
patients |>
  group_by(sex) |>
  summarise(n = n(), mean_age = mean(age), prop_vaccinated = mean(vaccinated))
## # A tibble: 2 × 4
##   sex        n mean_age prop_vaccinated
##   <chr>  <int>    <dbl>           <dbl>
## 1 female     3     31.3           0.667
## 2 male       2     23.5           0.5

P1.9.2 Formatos longo e largo

Os dados em formato largo têm uma coluna por variável ou período; os dados em formato longo têm uma linha por observação e uma coluna que identifica a variável. O formato longo é exigido pelo ggplot2.

wide <- tibble(district = c("A", "B"), `2024` = c(120, 85), `2025` = c(140, 60))
long <- wide |> pivot_longer(-district, names_to = "year", values_to = "cases")
long
## # A tibble: 4 × 3
##   district year  cases
##   <chr>    <chr> <dbl>
## 1 A        2024    120
## 2 A        2025    140
## 3 B        2024     85
## 4 B        2025     60
long |> pivot_wider(names_from = year, values_from = cases)
## # A tibble: 2 × 3
##   district `2024` `2025`
##   <chr>     <dbl>  <dbl>
## 1 A           120    140
## 2 B            85     60

P1.10 Importar e exportar dados

O código seguinte ilustra a importação e a exportação de ficheiros. Os nomes my_data.csv, my_data.xlsx e my_data_clean.csv são exemplos fictícios, a substituir pelos nomes de ficheiros de dados reais guardados na pasta data/ do projeto.

# "my_data" é um exemplo: substitua-o pelo nome do seu próprio ficheiro
library(readr)
data <- read_csv("data/my_data.csv")          # ficheiros de texto com valores separados por vírgulas
library(readxl)
data <- read_excel("data/my_data.xlsx")       # ficheiros Excel
write_csv(data, "output/my_data_clean.csv")   # exportação

Depois de importado, um conjunto de dados deve ser inspecionado com head(), glimpse(), summary() e View().

P1.11 Gráficos com o ggplot2

Um gráfico ggplot2 é construído a partir de três componentes: um data frame, uma correspondência estética entre variáveis e propriedades visuais com aes(), e uma ou mais geometrias (geom_point(), geom_line(), geom_col(), geom_histogram(), etc.). Os títulos são acrescentados com labs() e os painéis com facet_wrap().

ggplot(long, aes(x = year, y = cases, fill = district)) +
  geom_col(position = "dodge") +
  labs(x = "Ano", y = "Número de casos", fill = "Distrito")
growth <- tibble(day = 0:30, children = 50 * 1.08^(0:30), adults = 30 * 1.05^(0:30)) |>
  pivot_longer(-day, names_to = "group", values_to = "cases")

ggplot(growth, aes(day, cases, colour = group)) +
  geom_line(linewidth = 1) +
  labs(x = "Dia", y = "Casos", colour = "Grupo etário")

P1.12 Números aleatórios

O R gera números aleatórios a partir de muitas distribuições de probabilidade, por exemplo runif() (uniforme), rnorm() (normal), rbinom() (binomial) e rpois() (de Poisson). set.seed() torna os resultados reprodutíveis.

set.seed(2027)
rnorm(3, mean = 0, sd = 1)
## [1] -0.9348780 -0.6938629 -0.5479451
rbinom(5, size = 10, prob = 0.3)
## [1] 4 2 6 5 4
sample(1:6, size = 4, replace = TRUE)   # quatro lançamentos de um dado
## [1] 4 1 6 4

P1.13 Erros e ajuda

As mensagens de erro indicam onde a execução falhou. As causas mais frequentes são nomes de objetos mal escritos (object 'x' not found), pacotes que não foram carregados (could not find function), parênteses ou aspas por fechar e código executado pela ordem errada. Pode obter-se mais ajuda nas páginas de ajuda (?função), na documentação dos pacotes (manuais de referência e vinhetas no CRAN, https://cran.r-project.org/web/packages/), no Epidemiologist R Handbook (disponível em português) e em fóruns em linha como o Stack Overflow e a Posit Community. Os assistentes de IA podem explicar mensagens de erro e sugerir código, mas as suas sugestões devem ser verificadas e compreendidas antes de serem utilizadas.

DicaExercício
  1. Crie um vetor com os números semanais de casos 3, 7, 12, 25, 31 e 28. Calcule o total, a média e a semana com o maior número de casos.
  2. Escreva uma função percent_change(old, new) que devolva a variação percentual entre dois valores e aplique-a às semanas consecutivas do vetor acima (sugestão: x[-1] e x[-length(x)]).
  3. Utilizando o data frame patients, calcule a proporção de vacinados entre as crianças e entre os adultos.
  4. Crie um data frame com duas colunas, week (1 a 6) e cases (o vetor da pergunta 1), e represente os casos num gráfico de barras.
NotaSolução 
x <- c(3, 7, 12, 25, 31, 28)
c(total = sum(x), mean = mean(x), peak_week = which.max(x))
##     total      mean peak_week 
## 106.00000  17.66667   5.00000
percent_change <- function(old, new) (new - old) / old * 100
round(percent_change(x[-length(x)], x[-1]), 1)
## [1] 133.3  71.4 108.3  24.0  -9.7
patients |>
  mutate(group = ifelse(age >= 15, "adulto", "criança")) |>
  group_by(group) |>
  summarise(prop_vaccinated = mean(vaccinated))
## # A tibble: 2 × 2
##   group   prop_vaccinated
##   <chr>             <dbl>
## 1 adulto            0.667
## 2 criança           0.5
tibble(week = 1:6, cases = x) |>
  ggplot(aes(week, cases)) +
  geom_col(fill = "steelblue") +
  labs(x = "Semana", y = "Casos")
