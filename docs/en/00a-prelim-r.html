P1 Introduction to R

Preliminary learning — R and RStudio basics

TipLearning objectives

By the end of this chapter, participants should be able to:

  1. Use the RStudio interface, create and save scripts, and work within an RStudio Project.
  2. Create objects of the principal data types, and select elements of vectors and data frames.
  3. Use built-in functions and packages, consult help pages and write simple functions.
  4. Import a dataset and manipulate it with the principal tidyverse functions.
  5. Produce basic graphs with ggplot2.
  6. Use conditional statements and for loops.

This chapter introduces the basic elements of the R language. It does not assume previous programming experience. The application of R to the analysis of outbreak data and to modelling is the subject of course book: Own data and programming models in R in Module 1, and R is used in the practical sessions of every chapter of the book. Installation instructions are given in Appendix A — Installation of R and RStudio.

P1.2 RStudio and projects

RStudio has four panels: the script editor (top left), in which code is written and saved; the console (bottom left), in which code is executed; the environment (top right), which lists the objects in memory; and the files, plots and help panel (bottom right). A line of code in a script is executed with Ctrl + Enter (Cmd + Enter on macOS); text after # is a comment and is not executed.

Work should be organised in an RStudio Project (File → New Project). All file paths are then relative to the project folder, so that the analysis can be moved to another computer without modification.

P1.4 Objects and assignment

Values are stored in objects with the assignment operator <-. Object names are case-sensitive, cannot start with a number, and should be informative.

population <- 250000
cases <- 375
incidence <- cases / population * 100000
incidence
## [1] 150

P1.5 Data types and vectors

A vector is an ordered collection of values of the same type, created with c(). The principal types are numeric, character (text), logical (TRUE/FALSE), factor (categorical variable with defined levels) and date.

age <- c(4, 12, 35, 67, 23)                              # numeric
sex <- c("female", "male", "male", "female", "female")   # character
vaccinated <- c(TRUE, FALSE, TRUE, TRUE, FALSE)          # logical
age_group <- factor(c("0-14", "0-14", "15-64", "65+", "15-64"),
                    levels = c("0-14", "15-64", "65+"))  # factor
visit <- as.Date(c("2026-03-01", "2026-03-04", "2026-03-04", "2026-03-09", "2026-03-12"))

class(age); class(sex); class(vaccinated); class(age_group); class(visit)
## [1] "numeric"
## [1] "character"
## [1] "logical"
## [1] "factor"
## [1] "Date"
length(age)
## [1] 5

Arithmetic and comparisons are vectorised: they are applied to each element.

age * 12                   # age in months
## [1]  48 144 420 804 276
age >= 15                  # logical vector
## [1] FALSE FALSE  TRUE  TRUE  TRUE
sum(vaccinated)            # TRUE counts as 1
## [1] 3
mean(vaccinated)           # proportion vaccinated
## [1] 0.6
table(age_group)
## age_group
##  0-14 15-64   65+ 
##     2     2     1

P1.5.1 Selecting elements

age[2]                     # second element
## [1] 12
age[c(1, 3)]               # first and third elements
## [1]  4 35
age[-1]                    # all except the first
## [1] 12 35 67 23
age[age >= 15]             # elements meeting a condition
## [1] 35 67 23
sex[vaccinated]            # sex of vaccinated persons
## [1] "female" "male"   "female"

P1.5.2 Missing values

Missing values are represented by NA. Most summary functions return NA if any value is missing, unless na.rm = TRUE is specified.

weight <- c(12.5, NA, 70.2, 64.0, 58.3)
mean(weight)
## [1] NA
mean(weight, na.rm = TRUE)
## [1] 51.25
is.na(weight)
## [1] FALSE  TRUE FALSE FALSE FALSE
sum(is.na(weight))
## [1] 1

P1.6 Functions and packages

A function takes inputs (arguments) and returns an output. Arguments can be given by position or by name; arguments with default values can be omitted.

round(123.456, digits = 1)
## [1] 123.5
seq(from = 0, to = 20, by = 5)
## [1]  0  5 10 15 20
rep("A", times = 3)
## [1] "A" "A" "A"
paste("District", 1:3)
## [1] "District 1" "District 2" "District 3"

Additional functions are provided by packages. A package is installed once with install.packages("name") and loaded in each session with library(name). The help page of a function is displayed with ?function_name, e.g. ?seq.

P1.6.1 Writing functions

User-defined functions avoid repeating code:

incidence_per_100k <- function(cases, population) {
  cases / population * 100000
}
incidence_per_100k(cases = 375, population = 250000)
## [1] 150
incidence_per_100k(cases = c(10, 50, 120), population = c(20000, 80000, 150000))
## [1] 50.0 62.5 80.0

P1.7 Conditional statements and loops

if executes code only when a condition is true; ifelse() applies a condition to every element of a vector.

coverage <- 0.82
if (coverage >= 0.95) {
  message("Coverage target reached")
} else {
  message("Coverage below target")
}

ifelse(age >= 15, "adult", "child")
## [1] "child" "child" "adult" "adult" "adult"

A for loop repeats a block of code for each value of a sequence:

savings <- numeric(5)        # empty vector of length 5
savings[1] <- 100
for (year in 2:5) {
  savings[year] <- savings[year - 1] * 1.10   # 10% interest per year
}
savings
## [1] 100.00 110.00 121.00 133.10 146.41

P1.8 Lists

A list can contain objects of different types and lengths, and is often used to store parameters or the results of an analysis.

parameters <- list(country = "Mozambique", year = 2026, rates = c(0.1, 0.25))
parameters$country
## [1] "Mozambique"
parameters[["rates"]]
## [1] 0.10 0.25

P1.9 Data frames

A data frame is a table in which each column is a vector and each row an observation. A tibble is the tidyverse version of a data frame.

library(tidyverse)

patients <- tibble(
  id = 1:5,
  age = age,
  sex = sex,
  vaccinated = vaccinated,
  visit = visit
)
patients
## # A tibble: 5 × 5
##      id   age sex    vaccinated visit     
##   <int> <dbl> <chr>  <lgl>      <date>    
## 1     1     4 female TRUE       2026-03-01
## 2     2    12 male   FALSE      2026-03-04
## 3     3    35 male   TRUE       2026-03-04
## 4     4    67 female TRUE       2026-03-09
## 5     5    23 female FALSE      2026-03-12
patients$age            # one column

P1.9.1 Data manipulation with dplyr

The principal functions of the dplyr package each perform one operation and are combined with the pipe |>:

Function Operation
filter() select rows
select() select columns
mutate() create or modify columns
arrange() sort rows
group_by() and summarise() summarise by group
count() count rows by group
left_join() combine two tables by a common column 
patients |>
  filter(age >= 15) |>
  mutate(age_months = age * 12) |>
  select(id, sex, age, age_months) |>
  arrange(desc(age))
## # A tibble: 3 × 4
##      id sex      age age_months
##   <int> <chr>  <dbl>      <dbl>
## 1     4 female    67        804
## 2     3 male      35        420
## 3     5 female    23        276
patients |>
  group_by(sex) |>
  summarise(n = n(), mean_age = mean(age), prop_vaccinated = mean(vaccinated))
## # A tibble: 2 × 4
##   sex        n mean_age prop_vaccinated
##   <chr>  <int>    <dbl>           <dbl>
## 1 female     3     31.3           0.667
## 2 male       2     23.5           0.5

P1.9.2 Long and wide formats

Data in wide format have one column per variable or time point; data in long format have one row per observation and a column identifying the variable. Long format is required by ggplot2.

wide <- tibble(district = c("A", "B"), `2024` = c(120, 85), `2025` = c(140, 60))
long <- wide |> pivot_longer(-district, names_to = "year", values_to = "cases")
long
## # A tibble: 4 × 3
##   district year  cases
##   <chr>    <chr> <dbl>
## 1 A        2024    120
## 2 A        2025    140
## 3 B        2024     85
## 4 B        2025     60
long |> pivot_wider(names_from = year, values_from = cases)
## # A tibble: 2 × 3
##   district `2024` `2025`
##   <chr>     <dbl>  <dbl>
## 1 A           120    140
## 2 B            85     60

P1.10 Importing and exporting data

The code below illustrates the import and export of files. The names my_data.csv, my_data.xlsx and my_data_clean.csv are hypothetical examples, to be replaced by the names of actual data files stored in the data/ folder of the project.

# "my_data" is a placeholder: replace it with the name of your own file
library(readr)
data <- read_csv("data/my_data.csv")          # text files with comma-separated values
library(readxl)
data <- read_excel("data/my_data.xlsx")       # Excel files
write_csv(data, "output/my_data_clean.csv")   # export

After importing a dataset, it should be inspected with head(), glimpse(), summary() and View().

P1.11 Graphs with ggplot2

A ggplot2 graph is constructed from three components: a data frame, an aesthetic mapping of variables to visual properties with aes(), and one or more geometries (geom_point(), geom_line(), geom_col(), geom_histogram(), etc.). Labels are added with labs() and panels with facet_wrap().

ggplot(long, aes(x = year, y = cases, fill = district)) +
  geom_col(position = "dodge") +
  labs(x = "Year", y = "Number of cases", fill = "District")
growth <- tibble(day = 0:30, children = 50 * 1.08^(0:30), adults = 30 * 1.05^(0:30)) |>
  pivot_longer(-day, names_to = "group", values_to = "cases")

ggplot(growth, aes(day, cases, colour = group)) +
  geom_line(linewidth = 1) +
  labs(x = "Day", y = "Cases", colour = "Age group")

P1.12 Random numbers

R generates random numbers from many probability distributions, for example runif() (uniform), rnorm() (normal), rbinom() (binomial) and rpois() (Poisson). set.seed() makes the results reproducible.

set.seed(2027)
rnorm(3, mean = 0, sd = 1)
## [1] -0.9348780 -0.6938629 -0.5479451
rbinom(5, size = 10, prob = 0.3)
## [1] 4 2 6 5 4
sample(1:6, size = 4, replace = TRUE)   # four throws of a die
## [1] 4 1 6 4

P1.13 Errors and help

Error messages indicate where execution failed. Common causes include misspelled object names (object 'x' not found), packages that have not been loaded (could not find function), unmatched brackets or quotes, and code executed in the wrong order. Further help is available from the help pages (?function), the package documentation (reference manuals and vignettes on CRAN, https://cran.r-project.org/web/packages/), the Epidemiologist R Handbook and online forums such as Stack Overflow and Posit Community. AI assistants can explain error messages and suggest code, but their suggestions must be checked and understood before use.

TipExercise
  1. Create a vector with the weekly numbers of cases 3, 7, 12, 25, 31 and 28. Calculate the total, the mean and the week with the highest number of cases.
  2. Write a function percent_change(old, new) that returns the percentage change between two values, and apply it to consecutive weeks of the vector above (hint: x[-1] and x[-length(x)]).
  3. Using the patients data frame, calculate the proportion vaccinated among children and adults.
  4. Create a data frame with two columns, week (1–6) and cases (the vector of question 1), and plot the cases as a bar chart.
NoteSolution 
x <- c(3, 7, 12, 25, 31, 28)
c(total = sum(x), mean = mean(x), peak_week = which.max(x))
##     total      mean peak_week 
## 106.00000  17.66667   5.00000
percent_change <- function(old, new) (new - old) / old * 100
round(percent_change(x[-length(x)], x[-1]), 1)
## [1] 133.3  71.4 108.3  24.0  -9.7
patients |>
  mutate(group = ifelse(age >= 15, "adult", "child")) |>
  group_by(group) |>
  summarise(prop_vaccinated = mean(vaccinated))
## # A tibble: 2 × 2
##   group prop_vaccinated
##   <chr>           <dbl>
## 1 adult           0.667

tibble(week = 1:6, cases = x) |>
