P1 Introduction à R

Apprentissage préliminaire — bases de R et RStudio

NoteTraduction provisoire

Ce chapitre a été traduit de l’anglais et est en cours de relecture. Les remarques sont les bienvenues.

AstuceObjectifs d’apprentissage

À la fin de ce chapitre, les participants devraient être capables de :

  1. Utiliser l’interface de RStudio, créer et enregistrer des scripts, et travailler dans un projet RStudio.
  2. Créer des objets des principaux types de données, et sélectionner des éléments de vecteurs et de tableaux de données.
  3. Utiliser des fonctions intégrées et des packages, consulter les pages d’aide et écrire des fonctions simples.
  4. Importer un jeu de données et le manipuler avec les principales fonctions du tidyverse.
  5. Produire des graphiques simples avec ggplot2.
  6. Utiliser des instructions conditionnelles et des boucles for.

Ce chapitre présente les éléments de base du langage R. Il ne suppose aucune expérience préalable de la programmation. L’application de R à l’analyse des données d’épidémies et à la modélisation fait l’objet de livre du cours : Own data and programming models in R dans le module 1, et R est utilisé dans les séances pratiques de chaque chapitre du livre. Les instructions d’installation figurent dans Annexe A — Installation de R et RStudio.

P1.2 RStudio et les projets

RStudio comporte quatre panneaux : l’éditeur de scripts (en haut à gauche), dans lequel le code est écrit et enregistré ; la console (en bas à gauche), dans laquelle le code est exécuté ; l’environnement (en haut à droite), qui liste les objets en mémoire ; et le panneau fichiers, graphiques et aide (en bas à droite). Une ligne de code d’un script est exécutée avec Ctrl + Entrée (Cmd + Entrée sous macOS) ; le texte qui suit # est un commentaire et n’est pas exécuté.

Le travail doit être organisé dans un projet RStudio (File → New Project). Tous les chemins d’accès aux fichiers sont alors relatifs au dossier du projet, de sorte que l’analyse peut être déplacée vers un autre ordinateur sans modification.

P1.4 Objets et affectation

Les valeurs sont stockées dans des objets à l’aide de l’opérateur d’affectation <-. Les noms d’objets distinguent les majuscules des minuscules, ne peuvent pas commencer par un chiffre et doivent être explicites.

population <- 250000
cases <- 375
incidence <- cases / population * 100000
incidence
## [1] 150

P1.5 Types de données et vecteurs

Un vecteur est une suite ordonnée de valeurs du même type, créée avec c(). Les principaux types sont numérique, caractère (texte), logique (TRUE/FALSE), facteur (variable catégorielle avec des modalités définies) et date.

age <- c(4, 12, 35, 67, 23)                              # numérique
sex <- c("female", "male", "male", "female", "female")   # caractère
vaccinated <- c(TRUE, FALSE, TRUE, TRUE, FALSE)          # logique
age_group <- factor(c("0-14", "0-14", "15-64", "65+", "15-64"),
                    levels = c("0-14", "15-64", "65+"))  # facteur
visit <- as.Date(c("2026-03-01", "2026-03-04", "2026-03-04", "2026-03-09", "2026-03-12"))

class(age); class(sex); class(vaccinated); class(age_group); class(visit)
## [1] "numeric"
## [1] "character"
## [1] "logical"
## [1] "factor"
## [1] "Date"
length(age)
## [1] 5

Les opérations arithmétiques et les comparaisons sont vectorisées : elles s’appliquent à chaque élément.

age * 12                   # âge en mois
## [1]  48 144 420 804 276
age >= 15                  # vecteur logique
## [1] FALSE FALSE  TRUE  TRUE  TRUE
sum(vaccinated)            # TRUE compte pour 1
## [1] 3
mean(vaccinated)           # proportion de personnes vaccinées
## [1] 0.6
table(age_group)
## age_group
##  0-14 15-64   65+ 
##     2     2     1

P1.5.2 Valeurs manquantes

Les valeurs manquantes sont représentées par NA. La plupart des fonctions de résumé renvoient NA si une valeur est manquante, sauf si na.rm = TRUE est précisé.

weight <- c(12.5, NA, 70.2, 64.0, 58.3)
mean(weight)
## [1] NA
mean(weight, na.rm = TRUE)
## [1] 51.25
is.na(weight)
## [1] FALSE  TRUE FALSE FALSE FALSE
sum(is.na(weight))
## [1] 1

P1.6 Fonctions et packages

Une fonction reçoit des entrées (arguments) et renvoie un résultat. Les arguments peuvent être donnés par position ou par nom ; les arguments qui ont une valeur par défaut peuvent être omis.

round(123.456, digits = 1)
## [1] 123.5
seq(from = 0, to = 20, by = 5)
## [1]  0  5 10 15 20
rep("A", times = 3)
## [1] "A" "A" "A"
paste("District", 1:3)
## [1] "District 1" "District 2" "District 3"

Des fonctions supplémentaires sont fournies par des packages. Un package est installé une seule fois avec install.packages("nom") et chargé à chaque session avec library(nom). La page d’aide d’une fonction s’affiche avec ?nom_de_la_fonction, par ex. ?seq.

P1.6.1 Écrire des fonctions

Les fonctions définies par l’utilisateur évitent de répéter du code :

incidence_per_100k <- function(cases, population) {
  cases / population * 100000
}
incidence_per_100k(cases = 375, population = 250000)
## [1] 150
incidence_per_100k(cases = c(10, 50, 120), population = c(20000, 80000, 150000))
## [1] 50.0 62.5 80.0

P1.7 Instructions conditionnelles et boucles

if exécute du code uniquement lorsqu’une condition est vraie ; ifelse() applique une condition à chaque élément d’un vecteur.

coverage <- 0.82
if (coverage >= 0.95) {
  message("Objectif de couverture atteint")
} else {
  message("Couverture inférieure à l'objectif")
}

ifelse(age >= 15, "adulte", "enfant")
## [1] "enfant" "enfant" "adulte" "adulte" "adulte"

Une boucle for répète un bloc de code pour chaque valeur d’une séquence :

savings <- numeric(5)        # vecteur vide de longueur 5
savings[1] <- 100
for (year in 2:5) {
  savings[year] <- savings[year - 1] * 1.10   # intérêt de 10 % par an
}
savings
## [1] 100.00 110.00 121.00 133.10 146.41

P1.8 Listes

Une liste peut contenir des objets de types et de longueurs différents ; elle est souvent utilisée pour stocker des paramètres ou les résultats d’une analyse.

parameters <- list(country = "Mozambique", year = 2026, rates = c(0.1, 0.25))
parameters$country
## [1] "Mozambique"
parameters[["rates"]]
## [1] 0.10 0.25

P1.9 Tableaux de données

Un tableau de données (data frame) est un tableau dans lequel chaque colonne est un vecteur et chaque ligne une observation. Un tibble est la version tidyverse d’un tableau de données.

library(tidyverse)

patients <- tibble(
  id = 1:5,
  age = age,
  sex = sex,
  vaccinated = vaccinated,
  visit = visit
)
patients
## # A tibble: 5 × 5
##      id   age sex    vaccinated visit     
##   <int> <dbl> <chr>  <lgl>      <date>    
## 1     1     4 female TRUE       2026-03-01
## 2     2    12 male   FALSE      2026-03-04
## 3     3    35 male   TRUE       2026-03-04
## 4     4    67 female TRUE       2026-03-09
## 5     5    23 female FALSE      2026-03-12
patients$age            # une colonne
## [1]  4 12 35 67 23
nrow(patients); ncol(patients)
## [1] 5
## [1] 5
summary(patients$age)

P1.9.1 Manipulation des données avec dplyr

Les principales fonctions du package dplyr effectuent chacune une seule opération et sont combinées avec le pipe |> :

Fonction Opération
filter() sélectionner des lignes
select() sélectionner des colonnes
mutate() créer ou modifier des colonnes
arrange() trier les lignes
group_by() et summarise() résumer par groupe
count() compter les lignes par groupe
left_join() combiner deux tableaux par une colonne commune 
patients |>
  filter(age >= 15) |>
  mutate(age_months = age * 12) |>
  select(id, sex, age, age_months) |>
  arrange(desc(age))
## # A tibble: 3 × 4
##      id sex      age age_months
##   <int> <chr>  <dbl>      <dbl>
## 1     4 female    67        804
## 2     3 male      35        420
## 3     5 female    23        276
patients |>
  group_by(sex) |>
  summarise(n = n(), mean_age = mean(age), prop_vaccinated = mean(vaccinated))
## # A tibble: 2 × 4
##   sex        n mean_age prop_vaccinated
##   <chr>  <int>    <dbl>           <dbl>
## 1 female     3     31.3           0.667
## 2 male       2     23.5           0.5

P1.9.2 Formats long et large

Les données au format large comportent une colonne par variable ou par période ; les données au format long comportent une ligne par observation et une colonne qui identifie la variable. Le format long est requis par ggplot2.

wide <- tibble(district = c("A", "B"), `2024` = c(120, 85), `2025` = c(140, 60))
long <- wide |> pivot_longer(-district, names_to = "year", values_to = "cases")
long
## # A tibble: 4 × 3
##   district year  cases
##   <chr>    <chr> <dbl>
## 1 A        2024    120
## 2 A        2025    140
## 3 B        2024     85
## 4 B        2025     60
long |> pivot_wider(names_from = year, values_from = cases)
## # A tibble: 2 × 3
##   district `2024` `2025`
##   <chr>     <dbl>  <dbl>
## 1 A           120    140
## 2 B            85     60

P1.10 Importer et exporter des données

Le code ci-dessous illustre l’importation et l’exportation de fichiers. Les noms my_data.csv, my_data.xlsx et my_data_clean.csv sont des exemples fictifs, à remplacer par les noms de fichiers de données réels enregistrés dans le dossier data/ du projet.

# "my_data" est un exemple : le remplacer par le nom de votre propre fichier
library(readr)
data <- read_csv("data/my_data.csv")          # fichiers texte à valeurs séparées par des virgules
library(readxl)
data <- read_excel("data/my_data.xlsx")       # fichiers Excel
write_csv(data, "output/my_data_clean.csv")   # exportation

Après l’importation, un jeu de données doit être inspecté avec head(), glimpse(), summary() et View().

P1.11 Graphiques avec ggplot2

Un graphique ggplot2 est construit à partir de trois éléments : un tableau de données, une correspondance esthétique entre les variables et les propriétés visuelles avec aes(), et une ou plusieurs géométries (geom_point(), geom_line(), geom_col(), geom_histogram(), etc.). Les titres des axes sont ajoutés avec labs() et les panneaux avec facet_wrap().

ggplot(long, aes(x = year, y = cases, fill = district)) +
  geom_col(position = "dodge") +
  labs(x = "Année", y = "Nombre de cas", fill = "District")
growth <- tibble(day = 0:30, children = 50 * 1.08^(0:30), adults = 30 * 1.05^(0:30)) |>
  pivot_longer(-day, names_to = "group", values_to = "cases")

ggplot(growth, aes(day, cases, colour = group)) +
  geom_line(linewidth = 1) +
  labs(x = "Jour", y = "Cas", colour = "Groupe d'âge")

P1.12 Nombres aléatoires

R génère des nombres aléatoires selon de nombreuses lois de probabilité, par exemple runif() (uniforme), rnorm() (normale), rbinom() (binomiale) et rpois() (de Poisson). set.seed() rend les résultats reproductibles.

set.seed(2027)
rnorm(3, mean = 0, sd = 1)
## [1] -0.9348780 -0.6938629 -0.5479451
rbinom(5, size = 10, prob = 0.3)
## [1] 4 2 6 5 4
sample(1:6, size = 4, replace = TRUE)   # quatre lancers de dé
## [1] 4 1 6 4

P1.13 Erreurs et aide

Les messages d’erreur indiquent où l’exécution a échoué. Les causes fréquentes sont des noms d’objets mal orthographiés (object 'x' not found), des packages qui n’ont pas été chargés (could not find function), des parenthèses ou des guillemets non fermés, et du code exécuté dans le mauvais ordre. Une aide supplémentaire est disponible dans les pages d’aide (?fonction), la documentation des packages (manuels de référence et vignettes sur le CRAN, https://cran.r-project.org/web/packages/), l’Epidemiologist R Handbook (disponible en français) et des forums en ligne tels que Stack Overflow et Posit Community. Les assistants d’IA peuvent expliquer les messages d’erreur et proposer du code, mais leurs suggestions doivent être vérifiées et comprises avant d’être utilisées.

AstuceExercice
  1. Créer un vecteur contenant les nombres hebdomadaires de cas 3, 7, 12, 25, 31 et 28. Calculer le total, la moyenne et la semaine qui compte le plus grand nombre de cas.
  2. Écrire une fonction percent_change(old, new) qui renvoie la variation en pourcentage entre deux valeurs, et l’appliquer aux semaines consécutives du vecteur ci-dessus (indice : x[-1] et x[-length(x)]).
  3. À l’aide du tableau de données patients, calculer la proportion de personnes vaccinées chez les enfants et chez les adultes.
  4. Créer un tableau de données à deux colonnes, week (1 à 6) et cases (le vecteur de la question 1), et représenter les cas sous forme de diagramme en barres.
NoteSolution 
x <- c(3, 7, 12, 25, 31, 28)
c(total = sum(x), mean = mean(x), peak_week = which.max(x))
##     total      mean peak_week 
## 106.00000  17.66667   5.00000
percent_change <- function(old, new) (new - old) / old * 100
round(percent_change(x[-length(x)], x[-1]), 1)
## [1] 133.3  71.4 108.3  24.0  -9.7
patients |>
  mutate(group = ifelse(age >= 15, "adulte", "enfant")) |>
  group_by(group) |>
  summarise(prop_vaccinated = mean(vaccinated))
## # A tibble: 2 × 2
##   group  prop_vaccinated
##   <chr>            <dbl>
## 1 adulte           0.667
## 2 enfant           0.5
tibble(week = 1:6, cases = x) |>
  ggplot(aes(week, cases)) +
  geom_col(fill = "steelblue") +
  labs(x = "Semaine", y = "Cas")
